# Agent Guide

- Generate everything as concisely and as short as possible. Don't generate anything that wasn't asked for.
- Before making any changes to the repo, refer to [DEVELOPMENT.md](docs/DEVELOPMENT.md).
- Multi-session work gets a doc in [scratchpad/](scratchpad/): state the goal, brainstorm against it, then iterate on implementation detail there. See its [README](scratchpad/README.md) for the conventions.
- Decisions worth keeping are summarized from the scratchpad into [DECISIONS.md](docs/DECISIONS.md) before the scratchpad is deleted.
- Tenets for various aspects of the agent is documented in [TENETS.md](docs/TENETS.md). Reference this before making any choices.
