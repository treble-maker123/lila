# Guideline for Writing E-mails

This document has guidance on how the data is generated.

## Datasets

- `emails_smoke.json` — tiny hand-written set used as the default in
  `src/main.py` for quick smoke runs.
- `emails_individual.json` — the single-E-mail evaluation set. Currently only the
  labels are scaffolded; subjects, bodies, `label.actions`, `label.draft`, and
  `difficulty` are left blank to be filled in by hand.

## Scaffolding

`emails_individual.json` is generated by `scripts/generate_individual.py`.
Regenerate it with:

```

```
