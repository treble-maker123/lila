# Scratchpad

This folder contains documents that corresponds to various work and are meant to be deleted once those are completed. Each doc states the goal, captures the brainstorm against it, then carries the implementation detail as it firms up. Decisions worth retaining are summarized into [DECISIONS.md](/docs/DECISIONS.md) before the doc is deleted.

Files in this direction should be named in this format `YYYYMMDD-<goal>.md`, each file should contain a status of whether the work is on-going or done, as well as relevant information for the agent to pick up the context.
